# LearnPlaywright_4X

A beginner-friendly workspace for practicing JavaScript fundamentals as a starting point for browser automation with Playwright. It currently contains small console-based examples.

## Project structure

```text
01_Cheaptor.js/
├── 02_Math.js
└── Hellowrold.js
```

## Run the example

Install [Node.js](https://nodejs.org/), then run either example from the project root:

```bash
node 01_Cheaptor.js/Hellowrold.js
node 01_Cheaptor.js/02_Math.js
```

The first script prints `Hello World`; the second prints the result of `2 * 2`. No additional packages are currently required.
