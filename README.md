# LearnPlaywright_4X

A beginner-friendly workspace for learning JavaScript fundamentals as a starting point for browser automation with Playwright. It currently contains console-based examples covering basic output, arithmetic, and `let` variable declarations.

## Project structure

```text
01_Cheaptor.js/
├── 02_Math.js
└── Hellowrold.js
02_JS_Keyword_Identifier/
├── 01_javascriptenginer.js
└── 02_letinjavascript.js
```

## Run the examples

Install [Node.js](https://nodejs.org/), then run an example from the project root:

```bash
node 01_Cheaptor.js/Hellowrold.js
node 01_Cheaptor.js/02_Math.js
node 02_JS_Keyword_Identifier/01_javascriptenginer.js
node 02_JS_Keyword_Identifier/02_letinjavascript.js
```

The scripts demonstrate simple console output, arithmetic, and declaring and using variables. No additional packages are currently required.
