# LearnPlaywright_4X

A beginner-friendly workspace for learning JavaScript fundamentals as a starting point for browser automation with Playwright. It contains console-based examples covering variables, identifiers, literals, operators, and increment/decrement behavior.

## Project structure

```text
01_Cheaptor.js/
├── 02_Math.js
└── Hellowrold.js
02_JS_Keyword_Identifier/
├── 01_javascriptenginer.js
├── 02_letinjavascript.js
├── 03_KeywordIdentifier.js
├── Identifierrule.js
├── Imp.js
└── KeywordIdentifierRule.js
03_JavaScript_Literals/
04_JS_Operator/
JS_Incre_Decre_Op/
```

## Run the examples

Install [Node.js](https://nodejs.org/), then run an example from the project root. For example:

```bash
node 01_Cheaptor.js/Hellowrold.js
node 01_Cheaptor.js/02_Math.js
node 02_JS_Keyword_Identifier/01_javascriptenginer.js
node 02_JS_Keyword_Identifier/02_letinjavascript.js
node JS_Incre_Decre_Op/07_q5.js
```

The increment/decrement examples explore prefix and postfix operators. In `07_q5.js`, postfix decrement returns the original value before reducing the variable, so the output is `10` followed by `9`. No additional packages are currently required.
